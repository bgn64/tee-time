Hole-score entry — control options

Every option starts UNSET (no default — that's what keeps "holes played" accurate), lets you enter ANY number, and most offer an X for "did not finish". Try each: tap to set, tap the chosen value again (or Clear) to return to unset. The readout shows what the app would store.

Current Par-relative chips + custom sheet

Today's control: −2…+2 around par, and ✕ opens a stepper sheet for anything else. Relative framing; no X/DNF; "any" is buried in a modal.

A Absolute number rail

Horizontal strip of actual stroke counts (scroll for higher), par marked, X at the end. Tap the number you made — no mental par math.

B Relative chips + “⋯ more” + X

Keeps the familiar −2…+2 chips, adds an inline X, and ⋯ expands a stepper for any value — so "any" isn't hidden in a modal.

C Stepper from empty + X

Shows “–” until you act. + begins at 1 and counts to any number; − at 1 clears back to unset. X marks DNF. Minimal, but slow for big numbers.

D Tap-to-open keypad

A single "enter score" field opens a number pad (any value, multi-digit), with X and ⌫. Compact in the row; fully flexible.

E Hybrid: absolute chips + # keypad + X

One-tap absolute chips centered on par for the common cases, an X, and # opens the keypad for anything unusual. Speed + full range.

All six store null until you act, so a hole only counts as played once a real value (a number or X) is entered. X would store a sentinel (e.g. a large stroke count or a dedicated "dnf" flag) — TBD if we add it. The stat-entry controls are untouched.
