# Design artifacts

`docs/` is for local visual mockups and historical design artifacts. The folder is ignored by git except for this README, so durable project guidance should live in the root or folder-level READMEs that GitHub displays automatically.

Use the root `README.md` for publishing and release steps.

## What belongs here

- Local HTML mockups.
- Visual experiments.
- Temporary design references that do not need to be reviewed in GitHub.

If a mockup or historical note becomes durable guidance, summarize the current behavior in the relevant folder README instead of adding a separate tracked markdown file.

## Conventions

- Prefer folder-level `README.md` files for durable documentation.
- Keep one-off artifacts untracked unless there is a specific reason to commit them.
- Do not put secrets, production exports, or real user data in mockups or design fixtures.
